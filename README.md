# sommarioz

<!-- badges: start -->

<!-- badges: end -->

The most important function in \$ is the **summary()** function. So, if
one fits any statistical model or generates a near-optimal statistical
design, the one should summarise the model or the design with
appropriate summary measures.

The Italian word for *summary* is *sommario*!

The goal of sommarioz is to provide functions and data sets that are
used in the case-studies of the e-book (Biometry:The 5Rs).

The link to the e-book is
<http://mario24freo.github.io/Biometry_The_5Rs> which is in a
draft/development phase and version 1 is planned to be released on
December 1, 2026.

## Installation

You can install the development version of sommarioz from
[GitHub](https://github.com/mario24Freo/sommarioz) with:

``` r
remotes::install_github("mario24Freo/sommarioz")
```
